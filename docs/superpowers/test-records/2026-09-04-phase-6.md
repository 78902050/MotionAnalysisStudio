# 阶段 6 测试记录：三维运动学与技术指标

## 实现范围

- `Trajectory`：帧号、时间、关节点名、XYZ 坐标、单位、坐标系、输入路径和输入版本。
- TRC 读取：解析 Pose2Sim/OpenSim TRC 头部单位、采样率和标记名称。
- 单位转换：支持 m、cm、mm，拒绝未声明或不支持的单位。
- 指标：位置 XYZ、速度、加速度、角度、角速度和对称性差值。
- 缺口规则：NaN/缺失标签继续传播；有限差分和滤波只处理连续有限片段，不跨缺口连接。
- 溯源：每个指标列记录输入标签、输入路径/版本、采样率、坐标系、单位和滤波参数。
- GUI：运动学页面使用 `QThread` 后台计算，支持轨迹输入、采样率、单位和滤波选择；结果返回前检查项目 ID 与 generation。

## 已知限制

- TRC 文件本身没有统一声明坐标系名称，调用方必须显式提供坐标系；页面当前以 `world` 作为项目轨迹读取约定。
- 当前页面默认读取项目 `pose-3d` 目录排序后的第一个 TRC 文件；人物/试次选择将在阶段八对比工作台完善。
- 当前滤波提供缺口安全的移动平均和中值滤波；Pose2Sim 已生成的专用 Butterworth/LSTM 结果作为输入读取，不在本阶段重复实现第三方滤波算法。
- 指标表目前提供内存对象和 `to_dict()` 序列化接口，报告文件导出属于阶段八。
