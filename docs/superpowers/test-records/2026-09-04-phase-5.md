# 阶段 5 测试记录：人工确认的多人关联

## 验证范围

- 建立 `AssociationCandidate`、`AssociationOverride`、骨架指纹、轨迹分段和关联问题模型。
- 读取统一 `results.json` 与 Pose2Sim 实际使用的 `*_json/*.json` 文件层。
- 对多人数组顺序变化使用显式原始人物索引定位，不把数组顺序当作身份。
- 候选仅供人工确认；未确认候选不会写入关联结果。
- 关联结果采用原子替换，首次物化前备份，支持恢复，并在确认后仅使三角化及下游阶段失效。
- 关联页面使用后台线程执行扫描，项目切换和关闭时忽略或取消过期任务。
- 兼容真实样本中的全 NaN 人员和空 `{}` 缺失检测占位对象。
