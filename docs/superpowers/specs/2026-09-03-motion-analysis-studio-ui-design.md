# Motion Analysis Studio 界面与交互设计

## 1. 设计目标

界面必须让用户在较小屏幕上仍能看清当前上下文、任务状态和可操作控件。二维修正和三维质检内容多、信息密度高，因此采用可调整分栏、滚动容器和分页面组织，而不是把所有控件压进一张固定页面。

## 2. 全局窗口结构

主窗口使用 `QMainWindow`，结构固定为：

```text
┌─────────────────────────────────────────────────────────────┐
│ 项目栏：项目名 | 当前阶段 | 后台任务 | 保存状态 | 设置       │
├────────────┬────────────────────────────────────────────────┤
│ 导航栏     │ 当前页面 QStackedWidget                        │
│ 可折叠     │                                                │
│            │                                                │
└────────────┴────────────────────────────────────────────────┘
```

导航页顺序为：项目、视频素材、相机标定、同步、二维质检、二维修正、多人关联、三维质检、运动学、事件周期、对比报告、任务与日志、设置。

导航栏可折叠；折叠后只显示图标和当前页提示，展开状态保存到 `QSettings`。

## 3. 通用布局规则

- 所有信息密集页面的控制区域放进 `QScrollArea`，垂直滚动策略为 `ScrollBarAsNeeded`。
- 二维修正、三维质检、多相机同步和对比页面使用 `QSplitter`，分隔条可拖动。
- 关键画布设置 `QSizePolicy.Expanding`；操作面板设置最小宽度但允许扩展。
- 不使用依赖固定像素定位的绝对布局；表单使用 `QFormLayout` 或 `QGridLayout`。
- 主要动作固定放在页面底部工具栏或右侧操作区；滚动时仍能找到保存/取消动作。
- 错误、警告和阻塞状态必须同时有颜色、图标和文字，不只依赖颜色。

## 4. 窗口尺寸门禁

### 1120×720

- 主窗口不得出现控件重叠、文本截断到无法识别、按钮被挤出可见区域。
- 左侧导航宽度可在 180～280 px 调整。
- 画布区域优先保留空间；右侧详情面板可缩到 260 px 但仍能显示字段名。
- 2 路相机默认并排，4 路相机使用 2×2 网格。

### 620×480

- 所有控件必须通过滚动和分栏访问，不要求一次全部可见。
- 当前对象、保存状态、取消/保存动作必须在当前页面可找到。
- 画布可以缩小，但不能被隐藏；相机视图可以切换为单路模式。
- 不允许因最小窗口尺寸强制用户扩大到超出屏幕。

## 5. 二维质检页面

页面使用三栏 `QSplitter`：

```text
左栏（问题队列） | 中栏（1/2/4 路画布） | 右栏（定位与指标）
```

左栏：

- 问题筛选：相机、严重程度、处理状态、人物、关节点；
- 列显示：时间轴、帧号、相机、人物语义、关节点名、严重程度、处理状态、修改次数；
- 上一问题、下一问题、定位到修正页；
- 同一帧同一人物同一关节点的问题合并显示，证据放入详情。

中栏：

- 显示当前帧和前后帧缩略图；
- 支持 1、2、4 路视图，超过 4 路时提供相机选择；
- 所有视图使用相同时间轴；
- 显示“同步帧”和“原视频帧”，不能用一个数字代替两者；
- 鼠标滚轮以指针为中心缩放，拖动平移，缩放范围 100%～800%；
- 视图帧读取失败只影响对应卡片，并显示相机名、帧号和失败原因。

右栏：

- 当前目标的完整语义地址；
- 关联到的同步帧、原视频帧、人物和关节点；
- 坐标、置信度、重投影误差、参与相机数和插值状态；
- 候选项列表；候选不唯一时默认不选中；
- 跳转到二维修正和查看历史。

## 6. 二维修正页面

固定布局为：

```text
┌──────────────┬─────────────────────────┬──────────────────┐
│ 问题队列     │ 多相机联动画布           │ 当前目标详情     │
│ 筛选/状态    │ 1/2/4 路可调分栏         │ 相机/帧/人物/点   │
├──────────────┴─────────────────────────┴──────────────────┤
│ 时间轴 | 上/下一帧 | 撤销 | 重做 | 当前帧恢复 | 保存 | 保存并重跑 │
└─────────────────────────────────────────────────────────────┘
```

右侧详情在窄窗口中是滚动容器；表单字段顺序固定为相机、时间轴、同步帧、原视频帧、人物、关节点、X、Y、置信度、备注。

交互规则：

- 拖动点后置信度默认变为 `1.0`；
- 方向键按 `QSettings` 中的步长移动，Shift 为 5 倍；
- `Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做，`R` 恢复当前帧未保存修改，`Ctrl+S` 保存；
- 切换相机、帧、问题、项目或关闭窗口时，若有未保存更改，必须选择保存、放弃或取消；
- 取消导航后当前相机、帧、人物、关节点和画布状态保持不变；
- “当前帧恢复”只清理本次会话未保存的修改；“当前文件恢复”和“批次恢复”调用历史备份服务并写入新恢复记录。

## 7. 多人关联页面

页面顶部显示四个不同指标：实际项目人数、2D 检测人数、关联后同时人数、轨迹段数量。不能把最后一个直接命名为人物数。

中央使用人物轨迹时间轴显示轨迹段的连续区间、缺口和疑似身份切换。下方显示某相机/同步帧的候选列表：

- 精确候选可进入人工确认；
- 多候选不自动选择；
- 映射缺失、层缺失、输入损坏时显示阻塞原因；
- 只有用户点击“确认关联”后，保存按钮才可用。

## 8. 三维质检与分析页面

三维质检页面分为“质量概览”“轨迹时间轴”“问题详情”三个可切换子页，避免在一页垂直堆叠全部内容。质量概览显示重投影误差、有效关节点率、缺失率、插值率、双相机点比例和覆盖区间。

三维分析页使用顶部指标卡、中部 3D 视图、底部时间轴；角度、速度、加速度和事件列表放在可切换的右侧抽屉。指标卡只显示当前选择，详细数据通过表格和导出功能访问。

## 9. 任务与状态

顶部任务中心显示任务名称、所属项目、阶段、进度、取消按钮、日志位置和最终状态。后台任务完成后不自动跳页；仅在当前项目和请求 generation 仍匹配时更新页面。

## 10. 可访问性和文字规范

- 所有按钮有明确动词：保存、放弃、取消、确认关联、恢复当前文件、开始重跑；
- 不使用“应用”表示不明确的写入动作；
- 阻塞提示必须说明“为什么不能继续”和“需要用户做什么”；
- 表格支持键盘选择，当前行和当前控件有明显焦点样式；
- 中文路径和中文文件名直接显示，不强制转换为英文别名。
