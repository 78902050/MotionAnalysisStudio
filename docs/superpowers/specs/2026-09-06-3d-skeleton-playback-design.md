# 三维骨骼轨迹回放设计

日期：2026-09-06

## 目标

恢复项目内三维骨骼运动轨迹的交互播放能力。用户无需重新运行 Pose2Sim，即可选择已有 TRC 或 C3D，查看骨骼随时间运动，并进行播放、逐帧、倍速、视角、缩放和平移操作。播放器只读，不修改轨迹文件。

## 技术选择

采用原生 PySide6 `QWidget`/`QPainter` 画布和 NumPy 三维投影，不直接嵌入 Kinetics Toolkit Player，也不增加 PyQt5。

选择理由：

- 当前程序和冻结 EXE 以 PySide6 为唯一 Qt 绑定，避免再次引入 Qt DLL 冲突。
- 三维骨骼通常为 22～135 个点，QPainter 足以流畅绘制点、线、坐标轴和有限尾迹。
- 画布可在无显示服务器的 offscreen 测试中验证投影和生命周期。
- 当前环境已有 Pose2Sim 依赖 `c3d==0.6.0`，可读取真实 C3D 点轨迹，无需新增运行时依赖。

Kinetics Toolkit 作为算法与交互参考，不作为首版运行时依赖。

## 页面结构

新增独立导航页“三维回放”，避免继续压缩三维质检页面。

- 顶部：轨迹文件、人物/片段、处理版本、播放速度和循环开关。
- 中央：占据主要面积的三维画布。
- 右侧可调检查器：文件格式、帧率、帧范围、单位、标记数量、诊断和当前点坐标。
- 底部：播放/暂停、上一帧、下一帧、时间轴、当前帧/时间、回到起点、尾迹长度。
- 视角工具：正视、侧视、俯视、透视/正交切换、适应全部、旋转、平移和缩放。

中央画布与检查器使用可调 `QSplitter`；检查器可折叠。1120×720 不重叠，620×480 通过滚动和折叠访问控制项。

三维质检页增加“在三维回放中查看”入口，携带当前报告帧和人物语义定位；没有精确人物匹配时只打开文件选择器，不猜测人物。

## 轨迹来源与分组

新增统一只读来源模型：

```python
TrajectoryFormat = Literal["trc", "c3d"]

@dataclass(frozen=True)
class TrajectorySource:
    path: Path
    format: TrajectoryFormat
    trial_id: str
    person_id: str | None
    variant: str

@dataclass(frozen=True)
class TrajectoryDiagnostic:
    severity: Literal["info", "warning", "error"]
    code: str
    message: str

@dataclass(frozen=True)
class PlaybackTrajectory:
    frames: tuple[int, ...]
    times: tuple[float, ...]
    points: Mapping[str, tuple[Point3D, ...]]
    coordinate_unit: str
    source: TrajectorySource
    diagnostics: tuple[TrajectoryDiagnostic, ...]
```

文件按文件名中的试次、`P<number>` 和处理后缀分组。后缀只用于显示：原始、Butterworth、LSTM 或其他原文后缀；不得用处理后缀推断质量优劣。用户明确选择后才切换文件。

优先列出 TRC；对应 C3D 作为同一人物/版本的可选格式。只有 C3D 时仍可播放。

## TRC 与 C3D 读取

文件扫描在后台任务中进行，完整轨迹解析也在后台完成。项目切换、文件切换和关闭窗口会取消旧任务；结果必须携带 project ID 和 generation，旧结果不能覆盖当前项目。

TRC：

- 复用现有列解析规则、单位规范化和有限数判断。
- 播放读取器允许“头部声明帧数与实际可读数据行不一致”时加载实际行，但必须产生醒目的 `frame_count_mismatch` 警告并保留声明值和实际值。
- 帧号必须严格递增，时间必须严格递增；重复或倒退属于阻断错误。
- 当前严格分析入口继续拒绝帧数不一致，播放器容错不得静默改变分析结果。

C3D：

- 使用已安装的 `c3d.Reader` 读取点、帧号、采样率、标签和单位。
- 标签去除固定宽度尾随空格，但保留原始大小写。
- 点的 residual 表示无效时转换为 NaN；不得把缺失点显示在原点。
- 首版只读取点轨迹，不读取模拟量、力台或 OpenSim 网格，并在检查器中明确说明。
- C3D 解析失败只影响该文件，不阻止用户选择同组 TRC。

## 骨架语义与绘制

二维和三维共用 `SkeletonTopologyRepository`。播放器根据标签集合选择具有最高完整匹配度的 Pose2Sim 骨架定义；只有唯一匹配且关键躯干链存在时才画连线。无法唯一识别时只画点并显示原因。

每帧绘制：

- 骨骼边、关节点、世界坐标轴和可选地面网格。
- 当前点选择及其名称、坐标和缺失状态。
- 可配置 0～120 帧尾迹；尾迹按时间衰减透明度，不跨越 NaN 缺口连接。
- 所有有限点的边界用于“适应全部”；极端离群点只报告，不自动删除。

单位只影响检查器标签和适应视图，不在播放器中隐式转换。后续运动分析仍通过现有单位契约显式转换。

## 播放时钟与流畅性

解析完成后，轨迹驻留在只读内存对象中。播放使用 `QElapsedTimer` 计算目标时间，再通过轨迹时间数组定位帧；不使用“每次定时器加一帧”的累积方式，以免 GUI 停顿后永久漂移。

- GUI 定时器目标间隔 16 ms。
- 轨迹帧率高于实际绘制能力时跳过中间显示帧，但时间轴和最终位置保持正确。
- 暂停和逐帧严格落在真实帧号。
- 速度支持 0.25×、0.5×、1×、2×、4×。
- 项目切换、页面关闭和应用关闭必须停止定时器并取消解析任务。

## 投影与交互

三维点先平移到视图中心，再应用 yaw/pitch 旋转矩阵和缩放，最后投影到画布。正交投影作为默认，透视投影必须限制近裁剪面，避免点穿过相机后翻转。

- 左键拖动：旋转。
- Shift+左键或中键拖动：平移。
- 滚轮：缩放。
- 单击最近的可见点：选择标记。
- 视角和分栏尺寸存入 `QSettings`，项目数据中不写 UI 状态。

## 错误与准确性

- 无轨迹文件、空轨迹、未知单位、错误时间轴和解析异常必须在页面显示具体文件与原因。
- 缺失点保持 NaN，既不绘制也不以零替代。
- 骨架拓扑不确定时不连线。
- 播放器是可视化工具，不因“看起来平滑”改变源数据，也不覆盖 TRC/C3D。
- 同组 TRC/C3D 的帧数、标签或单位不一致时显示比较诊断，不自动选定其中一个为真值。

## 测试与验收

- 读取器测试覆盖规范 TRC、Pose2Sim 帧数差一的滤波 TRC、NaN、重复时间、C3D 标签尾空格和无效 residual。
- 投影测试使用手算坐标验证正视/侧视/俯视、缩放和适应全部。
- 播放时钟测试验证 0.25×～4×、暂停、逐帧、循环和 GUI 延迟后的时间定位。
- 页面测试覆盖文件/人物/版本选择、项目切换取消、诊断显示和窗口关闭清理。
- 使用 `D:\test\data` 中原始/Butterworth/LSTM TRC 和对应 C3D 做只读验收。
- 连续播放 10 秒时，Qt heartbeat 不得出现超过 250 ms 的事件循环停顿，内存不得随帧数持续增长。
- 完整 `unittest`、`compileall`、真实数据验收、EXE 重建和冻结产物 smoke 均须通过。

## 非目标与已知限制

- 首版不显示 OpenSim 骨骼网格或肌肉模型。
- 首版不展示 C3D 模拟量、力台和 EMG；这些数据只保留为后续扩展边界。
- 首版不在三维播放器内编辑轨迹点。
- 三维画布不替代二维人工修正，三维异常仍需跳转到对应二维相机证据后修改。
